# Student Grade Calculator

A simple beginner-friendly web application built with Python and Flask to calculate student total marks, percentage, and grade.

This project is being developed gradually, with new features added step by step to keep the code simple and easy to understand.

## Features

### Day 1

* Enter student name
* Enter marks for subjects
* Calculate total marks
* Calculate percentage
* Automatically calculate grade
* Basic input validation
* Simple and clean interface

### Day 2

* Add new subjects dynamically
* Remove subjects
* Enter different numbers of subjects
* Calculate total and percentage based on the subjects entered
* Validate subject names and marks

## Grade System

| Percentage | Grade |
| ---------- | ----- |
| 90–100     | A     |
| 80–89      | B     |
| 70–79      | C     |
| 60–69      | D     |
| Below 60   | F     |

## How to Run Locally

Install Flask:

```bash
pip install flask
```

Run the application:

```bash
python app.py
```

Then open the local URL provided by Flask in your browser.
